# Zahidul Turja - Portfolio

Welcome to my interactive portfolio built using **Next.js**, **Tailwind CSS**, and **GSAP**. This project showcases my skills, projects, blogs, and other relevant information in a structured and engaging manner.

## 🚀 Features

- **Modern UI/UX Design** using Tailwind CSS
- **Next.js** for a fast and optimized experience
- **Project and Blog Showcase**
- **Animations & Page Transitions** for smooth navigation
- **Video Player** integration
- **Reusable Components** for maintainability

## 📦 Installation & Setup

1. **Clone the Repository**
   ```sh
   git clone https://github.com/your-username/zahidul-turja-portfolio.git
   cd zahidul-turja-portfolio
   ```
2. **Install Dependencies**
   ```sh
   npm install
   ```
3. **Run the Development Server**
   ```sh
   npm run dev
   ```
   The app will be available at `http://localhost:3000`

## ⚙️ Configuration

- Modify `next.config.mjs` for custom Next.js configurations.
- Global styles are managed in `app/styles/globals.css`.
- Data is stored in `public/data/data.js`.

## 🛠️ Technologies Used

- **Next.js** - React framework for server-side rendering
- **Tailwind CSS** - Utility-first CSS framework
- **ESLint & Prettier** - Code linting and formatting
- **Framer Motion** - For smooth animations
- **React Hooks** - Efficient state and lifecycle management
